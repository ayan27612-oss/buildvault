# Voltly

A fast, mobile-first MVP for an on-demand electrical services marketplace.

## Concept
Voltly is positioned like a Blinkit-style service marketplace for electrical work: customers pick a job, see fast availability, choose a time, and submit a booking request.

## Included in this MVP
- Responsive landing page
- Service catalog: fan repair, switches/sockets, lighting, power issues, wiring, appliance connections
- Live-availability visual mockup
- Booking modal with service, address, and preferred time
- Responsive mobile layout
- No external dependencies or build step

## Run
Open `index.html` in a browser. Everything is self-contained in the file, because apparently sometimes the simplest stack is the least annoying one.
